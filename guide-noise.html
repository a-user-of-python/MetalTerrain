Noise Tuning

MTNoiseConfig is the soul of your world — nine knobs deciding between archipelago, rolling hills, jagged peaks, or canyonlands.

The pipeline: seeded permutation table → 2D gradient (Perlin) noise → fractal layers (fbm) → optional domain warp → normalized 0…1 height. Every stage is deterministic.

The knobs

seed (default 1337)

Which world. Turn this up for: a brand-new world when you like the style but not the layout.

octaves (default 5, range 1…12)

Detail layers. Lower (1–3): smooth, stylized. Higher (7–12): rich, craggy. Cost is roughly linear per octave — prefer 5–6 for interactive regeneration.

baseFrequency (default 0.008)

Most misunderstood knob: lower frequency = larger features. 0.004 → vast continents; 0.02 → busy, cramped bumps.

lacunarity (default 2.03)

How much finer each octave gets. Higher (2.5–3.5): crisp, crystalline. Lower (1.5–1.8): soft, weathered.

gain (default 0.5)

Amplitude falloff per octave. Higher (0.6–0.75): rough, chaotic. Lower (0.3–0.4): broad shapes dominate.

warpStrength (default 0.35, 0 = off)

Domain warp — the sample point is pushed around by a second noise field. This is what makes coastlines wind and valleys meander. 0.2–0.4 is the natural sweet spot; 0.6–1.0 gets wild and marbled.

warpFrequency (default 0.02)

Scale of the warp pattern. Tune with warpStrength: strong + low frequency = grand sweeping curves; strong + high frequency = tangled spaghetti.

ridged (default false)

Mountain mode. Each octave becomes (1 − |n|)² → sharp crests and V-valleys. The difference between hills and the Alps.

amplitude (default 1.0)

Overall multiplier before normalization. Prefer config.heightScale when you want the same shapes but taller in world units.

Recipes

Archipelago — scattered islands

var noise = MTNoiseConfig.default
noise.octaves = 4
noise.baseFrequency = 0.006      // broad features → distinct islands
noise.warpStrength = 0.55        // winding, organic coastlines
noise.ridged = false

var config = MTTerrainConfig.default
config.noise = noise
config.seaLevel = 0.58           // drown everything but the island tops
world.config = config

Rolling hills — gentle pastoral land

var noise = MTNoiseConfig.default
noise.octaves = 3
noise.baseFrequency = 0.006
noise.warpStrength = 0.45
noise.gain = 0.35                // broad shapes dominate
noise.ridged = false

var config = MTTerrainConfig.default
config.noise = noise
config.seaLevel = 0.40
config.heightScale = 40          // soft relief
world.config = config

Jagged peaks — alpine ridgelines

var noise = MTNoiseConfig.default
noise.octaves = 6
noise.baseFrequency = 0.010
noise.lacunarity = 2.2
noise.gain = 0.55
noise.warpStrength = 0.30
noise.ridged = true              // ← mountain mode

var config = MTTerrainConfig.default
config.noise = noise
config.seaLevel = 0.35
config.heightScale = 90
world.config = config

Then widen the snow band (Biome Authoring, Recipe 1) so peaks read as alpine.

Canyonlands — eroded plateaus and ravines

var noise = MTNoiseConfig.default
noise.octaves = 5
noise.baseFrequency = 0.012
noise.lacunarity = 2.6
noise.gain = 0.6
noise.warpStrength = 0.15        // keep strata readable
noise.ridged = true

var config = MTTerrainConfig.default
config.noise = noise
config.seaLevel = 0.30
config.heightScale = 70
world.config = config

Seed reproducibility

Guarantee: same seed + same config = same world, everywhere. heightAt(x:z:) is a pure function of the seed — gameplay code and rendered meshes can never disagree.

  • The structure field (config.structureNoise) has its own seed — re-roll structures without reshaping terrain.
  • Caveat: changing any noise knob produces a different world. Version your config alongside the seed if you ship seeds to users.
