Noise Tuning

MTNoiseConfig is the soul of your world — nine knobs deciding between archipelago, rolling hills, jagged peaks, or canyonlands.

The pipeline: seeded permutation table → 2D gradient (Perlin) noise → fractal layers (fbm) → optional domain warp → normalized 0…1 height. Every stage is deterministic.

The knobs

seed (default 1337)

Which world. Turn this up for: a brand-new world when you like the style but not the layout.

octaves (default 5, range 1…12)

Detail layers. Lower (1–3): smooth, stylized. Higher (7–12): rich, craggy. Cost is roughly linear per octave — prefer 5–6 for interactive regeneration.

baseFrequency (default 0.008)

Most misunderstood knob: lower frequency = larger features. 0.004 → vast continents; 0.02 → busy, cramped bumps.

lacunarity (default 2.03)

How much finer each octave gets. Higher (2.5–3.5): crisp, crystalline. Lower (1.5–1.8): soft, weathered.

gain (default 0.5)

Amplitude falloff per octave. Higher (0.6–0.75): rough, chaotic. Lower (0.3–0.4): broad shapes dominate.

warpStrength (default 0.35, 0 = off)

Domain warp — the sample point is pushed around by a second noise field. This is what makes coastlines wind and valleys meander. 0.2–0.4 is the natural sweet spot; 0.6–1.0 gets wild and marbled.

warpFrequency (default 0.02)

Scale of the warp pattern. Tune with warpStrength: strong + low frequency = grand sweeping curves; strong + high frequency = tangled spaghetti.

ridged (default false)

Mountain mode. Each octave becomes (1 − |n|)² → sharp crests and V-valleys. The difference between hills and the Alps.

amplitude (default 1.0)

Overall multiplier before normalization. Prefer config.heightScale when you want the same shapes but taller in world units.

Recipes

Archipelago — scattered islands

var noise = MTNoiseConfig.default
noise.octaves = 4
noise.baseFrequency = 0.006      // broad features → distinct islands
noise.warpStrength = 0.55        // winding, organic coastlines
noise.ridged = false

var config = MTTerrainConfig.default
config.noise = noise
config.seaLevel = 0.58           // drown everything but the island tops
world.config = config

Seed reproducibility

Guarantee: same seed + same config = same world, everywhere. heightAt(x:z:) is a pure function of the seed — gameplay code and rendered meshes can never disagree.

  • The structure field (config.structureNoise) has its own seed — re-roll structures without reshaping terrain.
  • Caveat: changing any noise knob produces a different world. Version your config alongside the seed if you ship seeds to users.

The height pipeline, layer by layer

height(x:y:config:) is not a single noise call — it's a small terrain synthesizer. Understanding the layers is what separates "random bumps" from "that looks like a real place". Layers run in this order:

  1. Continent mask (very low frequency, 2 octaves). Decides where the big landmasses and oceans are. Deliberately only 2 octaves — for something this smooth, a third octave is visually indistinguishable and costs ~19% more noise evaluations per vertex.
  2. Domain warp. When warpStrength > 0, the sample point itself is bent by a 3-octave fbm vector field before the main noise is evaluated. This is the single biggest "naturalness" lever: it turns blobby Perlin islands into coastlines with bays, peninsulas, and personality. Cost: a few extra noise evals per vertex — worth it.
  3. Base detail — fbm, or ridged multifractal when config.ridged is true (mountain mode: (1 − |n|)² per octave gives sharp crests instead of soft hills).
  4. Mountain ranges — a separate ridged noise at ~0.35× frequency (ranges span multiple chunks), masked so only ~35% of land gets mountains. Peaks are rounded with pow(ridged, 0.72) so summits look like mountains, not spikes.
  5. Rivers — carved where a warped low-frequency field is near zero, masked to land and reduced on mountainsides. Rivers carve down to just below sea level so they actually hold water.
  6. Combine + coastal shelf. Everything is summed, then heights near sea level are flattened toward a shelf value so beaches read as beaches instead of cliff-edged bathtubs. Final result is clamped to 0…1.
continent (0.18× freq, 2 oct) ──▶ land/ocean mask
detail (warped fbm | ridged) ──▶ hills
mountains (0.35× ridged, masked) ──▶ ranges
rivers (warped, carved to < sea) ──▶ valleys
            │ combine: h = 0.5 + continent·0.55 + detail·0.28 − mountains mask…
            ▼
   coastal shelf flatten ──▶ clamp 0…1 ──▶ height

Parameter guide — what each knob actually does

ParameterDefaultRangeEffect
seed1337any UInt64 Selects a completely different world. Same seed + same config = same world, always.
octaves51…12 (clamped) Detail layers. Each octave roughly doubles the triangle-level detail — and the cost. 3 = stylized/low-poly feel, 5 = natural default, 8+ = extremely rugged (and slow).
baseFrequency0.004> 0 How "zoomed in" the noise is. Halve it → features twice as wide (rolling continents). Double it → busy, choppy terrain. This is the coarsest feel control.
amplitude1.0> 0 Overall height of the detail layer. Rarely needs changing — prefer heightScale.
lacunarity2.03~1.5…4 Frequency multiplier per octave. 2.0 = classic; higher = finer grain between layers.
gain0.420…1 Amplitude multiplier per octave. Lower = smoother (high octaves contribute less); higher = rougher, more "crunchy" detail.
warpStrength0.250…~1 Domain-warp amount. 0 = classic blobby Perlin; 0.25 = natural coastlines; 0.6+ = swirly, surreal. Costs extra noise evals — set 0 for max speed.
warpFrequency0.015> 0 Scale of the warp field. Lower = broad bends (continental drift feel); higher = local squiggles.
ridgedfalsebool Mountain mode for the detail layer. Sharp crests and V-valleys instead of soft hills. Combine with the built-in mountain-range layer for the Alps; leave off for farmland.

Heads-up on stale comments: the doc comments on MTNoiseConfig's properties list older defaults (baseFrequency 0.008, gain 0.5, warpStrength 0.35, warpFrequency 0.02). The initializer defaults in the table above are authoritative.

Recipes

Rolling farmland with a distant mountain range (default-ish)

var noise = MTNoiseConfig()  // defaults are already this
noise.octaves = 4
noise.warpStrength = 0.25
noise.ridged = false

Alpine — sharp peaks everywhere

var noise = MTNoiseConfig()
noise.ridged = true
noise.octaves = 6
noise.gain = 0.5          // let high octaves bite
noise.warpStrength = 0.35 // dramatic ridgelines

Archipelago — scattered islands

Islands come from the continent layer, not the detail layer. Lower the continent influence by raising sea level instead of fighting the noise:

var config = MTTerrainConfig.default
config.seaLevel = 0.55   // drowns everything but the high bits → islands
config.noise.baseFrequency = 0.003  // broader continents = bigger island groups

Low-poly stylized

var noise = MTNoiseConfig()
noise.octaves = 2
noise.warpStrength = 0.0  // clean geometric shapes
noise.gain = 0.5

Maximum-performance noise (older devices)

var noise = MTNoiseConfig()
noise.octaves = 3
noise.warpStrength = 0.0  // skips the warp field entirely

Warp is the most expensive single toggle — disabling it saves several noise evaluations per vertex. Dropping from 5 to 3 octaves saves ~40% of noise cost.

Sampling API

Four public samplers. All are pure functions of (config, x, y) — note they rebuild the Perlin permutation table per call, so for bulk sampling use world.generateChunk(at:) (which builds tables once) instead of looping height(x:y:config:) yourself.

// Full terrain height in 0...1 (the one you want 99% of the time)
let h: Float = height(x: 1234.5, y: -678.0, config: config.noise)

// Raw fractal Brownian motion, roughly [-1, 1] — for custom masks
let f: Double = fbm(config.noise, x: x, y: y)

// Ridged multifractal in [0, 1] — sharp crests, for custom mountain logic
let r: Double = ridged(config.noise, x: x, y: y)

// Seeded 2D gradient noise in [-1, 1]; NaN/inf inputs safely return 0
let n = MTPerlinNoise(seed: 42)
let v: Double = n.noise(x: x, y: y)

// Deterministic PRNG for gameplay logic (loot, scatter, names)
var rng = MTSeededRandom(seed: world.seed ^ 0x9E3779B97F4A7C15)
let roll = rng.nextDouble()      // [0, 1)
let pick = rng.nextInt(upperBound: 7)

Performance notes

  • MTPerlinNoise.noise(x:y:) is called ~2M times per chunk at full resolution. It uses a bitwise & 255 lattice wrap instead of floating-point modulo (~20–50 cycles saved per call on ARM) — this is why chunk builds are fast, not because the math is simple.
  • Octaves are clamped to 1…12. Above ~8 you get diminishing visual returns for linearly increasing cost.
  • The continent mask deliberately uses 2 octaves instead of 3 — visually identical for something that smooth, ~19% cheaper per vertex.
  • If you sample heights yourself (minimaps, AI), prefer world.heightAt(x:z:) over the free functions — the world caches the permutation tables per seed.

Determinism contract

Every noise function is a pure function of (seed, x, y). There is no SystemRandomNumberGenerator, no Date, no I/O anywhere in the noise path. Consequences you can rely on:

  • The same seed renders the identical world on an iPhone SE and an iPad Pro.
  • Regenerating a chunk after eviction produces bit-identical heights.
  • Your minimap, spawn logic, and structure placement all agree with the renderer without any synchronization — they all call the same functions.
