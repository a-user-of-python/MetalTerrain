Migration Notes

What changed between versions, and what to do about it. Read the section for the version you're coming from.

Current defaults (authoritative)

Several doc comments in the source list outdated defaults. The initializer values below are what actually ships — if in doubt, trust the init signature, not the comment above the property:

ParameterActual defaultStale comment says
MTTerrainConfig.chunkResolution25096
MTTerrainConfig.chunkWorldSize1000128
MTTerrainConfig.heightScale40060
MTNoiseConfig.baseFrequency0.0040.008
MTNoiseConfig.gain0.420.5
MTNoiseConfig.warpStrength0.250.35
MTNoiseConfig.warpFrequency0.0150.02

If you copied the comment values into your config, your terrain was tuned against numbers that were never real — re-tune from the actual defaults.

Library-only split (v1.1)

MetalTerrain became library-only: the old Demo/ app was removed and now lives in the separate NativeMetalTerrain repository. If you forked the demo:

  • Library code → a-user-of-python/MetalTerrain (this repo).
  • App code (camera, input, UI) → your own app; use MTTerrainView.
  • New in the split: MTTerrainView (drop-in MTKView) and MTTerrainWorld.findSafeSpawn().

Chunk resolution raised (250)

chunkResolution moved 64 → 128 → 192 → 250 across releases as device headroom allowed. If you pinned 64 for performance, re-profile before assuming you still need to: the noise path is ~5× faster than it was (bitwise lattice wrap, fewer mask octaves, hoisted config, lock-free biome lookup).

LOD temporarily disabled

Half-resolution distant chunks are currently disabled (all chunks build full-res) while border stitching is implemented, to eliminate T-junction cracks. When LOD returns, buildLOD(for:world:distanceFactor:) will select strides again — no API change; distant chunks just get cheaper. If you wrote custom meshing against resolutionScale, keep passing it: generateChunk(at:resolutionScale:) still honors it.

Water contract hardened

Water is now contractually a flat plane: geometric displacement never touches water vertices, and there's no foam or shoreline effect. If you built custom water visuals on the old animated-geometry water, move the animation into the fragment shader.

Mirrors removed (app-level)

Live mirror reflections were removed from the reference car's implementation. The renderReflection(to:from:lookingAt:) API itself is unchanged and still available for app-level effects.

viewDistance max raised to 10

MTTerrainConfig.viewDistance clamps to 1…10 (was lower). The performance guide's budget math is quadratic — 10 is for M3-class devices or screenshots, not a default.

Checklist when upgrading

  1. Diff your pinned config against the authoritative defaults table above.
  2. Re-check spawn logic: findSafeSpawn() exists now — use it instead of hardcoded coordinates.
  3. If you used the demo app as a starting point, migrate camera/input/UI to MTTerrainView + onFrame.
  4. Re-profile on your lowest supported device; don't assume old tuning still applies.
