Skybox

MTSkybox is the library's sky renderer: a gradient sky dome with a visible sun disc. Works on all devices — not gated behind M3_FEATURES.

The skybox draws first each frame, behind everything, and its sun position matches the terrain's lighting direction (and the ray-traced shadow direction on M3-family GPUs).

Basic usage

public final class MTSkybox {
    public init(device: MTLDevice)
    public var sunAzimuth: Float      // radians, default points east-ish
    public var sunElevation: Float    // radians above the horizon
    public func draw(encoder: MTLRenderCommandEncoder,
                     viewProjection: matrix_float4x4)
}

With MTTerrainRenderer or MTTerrainView you don't even write the draw call:

renderer.skybox?.sunAzimuth = 0.8
renderer.skybox?.sunElevation = 0.5
// drawn automatically at the start of renderer.draw(in:)

renderer.skybox is created by default; set it to nil to disable sky rendering.

Sun semantics

PropertyMeaning
sunAzimuthHorizontal angle, radians. 0 = +X; increasing rotates toward +Z (right-handed about +Y). Full circle = 2π.
sunElevationVertical angle above horizon, radians. 0 = horizon, π/2 = overhead. Negative = below horizon (sky darkens).

Both are live: changing them takes effect on the next draw. The same angles drive terrain lighting, so the sky's sun disc and the light on the mountains always agree — move the sun and both move together. On M3-family builds, ray-traced shadows are traced toward this same position.

The same properties are mirrored on MTTerrainView (sunAzimuth, sunElevation) as a convenience.

Driving the sun from UI

// Example: sliders in degrees → radians for the skybox
let azimuthDeg: Float = 135    // compass-ish direction
let elevationDeg: Float = 25   // height above horizon

renderer.skybox?.sunAzimuth = azimuthDeg * .pi / 180
renderer.skybox?.sunElevation = elevationDeg * .pi / 180
// Terrain lighting follows automatically — same sun.

See also

  • MTSkybox in the API reference.
  • Ray Tracing — shadows traced toward this sun.

How it's drawn

The skybox is one fullscreen triangle rendered first each frame, at the far plane, with depth writes disabled. Everything else (terrain, structures, water) draws over it with normal depth testing. The gradient, sun disc, and stars are all procedural in sky_fragment — no textures.

  • Day (sunElevation > 0): horizon-to-zenith gradient with warm tint near the sun disc.
  • Golden hour (sunElevation ≈ 0): strong warm band at the horizon.
  • Night (sunElevation < 0): sun hidden, stars fade in.

Sun agreement invariant: the skybox uses the same azimuth/elevation → direction mapping as the terrain lighting, so the visible sun disc always agrees with the light direction shading the terrain. If you move the sun, both move together — the renderer mirrors its sunAzimuth/sunElevation into the skybox automatically before each draw.

API

// The renderer creates one by default; nil disables the sky.
renderer.skybox = nil            // no sky (clear color shows through)
renderer.skybox = MTSkybox(device: device)  // re-enable

// Sun position in degrees — mirrors renderer.sunAzimuth/sunElevation.
renderer.sunAzimuth = 135        // 0° = +Z, 90° = +X
renderer.sunElevation = 12       // low sun → long shadows, warm sky
renderer.sunElevation = -10      // night: stars, sun below horizon

// Via the view (forwarded):
terrainView.sunAzimuth = 135
terrainView.sunElevation = 12

Day/night cycle example

// 60-second day cycle driven from onFrame
var timeOfDay: Float = 0.25  // 0 = midnight, 0.5 = noon
terrainView.onFrame = { view, dt in
    timeOfDay += Float(dt) / 60.0
    if timeOfDay >= 1 { timeOfDay -= 1 }
    // Elevation: -30° (midnight) .. +65° (noon)
    view.sunElevation = sin((timeOfDay - 0.25) * 2 * .pi) * 47.5 + 17.5
    // Azimuth sweeps east → west
    view.sunAzimuth = timeOfDay * 360
    // ... camera code ...
}

Customization notes

  • There is no texture or gradient-stop API — the sky is fully procedural. To change the look (alien sky, different star density), you'd modify sky_fragment in the Metal sources; the mapping uniforms are the documented seam.
  • Fog color (config.fogColor) should roughly match your horizon color or distant terrain will visibly pop against the sky. The defaults are tuned to agree.
  • MTSkybox.draw(encoder:viewProjection:) sets its own pipeline, depth state (.lessEqual, no depth write), and cull mode (.none). If you call it manually in a custom renderer integration, re-set your terrain state afterward — the library renderer does this automatically.
