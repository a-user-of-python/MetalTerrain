MetalTerrain

A 3D terrain generation library for iOS — Swift + native Metal. Seeded infinite worlds with mountains, oceans, forests, and villages, rendered at 60 fps.

Design principle: the library owns everything Metal — LOD, shaders, pipelines, chunk streaming, instancing. Your app only handles what it must: the view hierarchy, camera, input, and UI.

The 30-second pitch

Add one Swift package, write five lines, and your app has an endless explorable 3D world: mountains, beaches, oceans, forests, snowy peaks, plus scattered low-poly structures — all deterministic from a single seed. Change the seed and get a brand-new planet. No assets, no textures, no physics engine, no third-party code.

Quickstart — 5 lines

import MetalTerrain

let terrainView = MTTerrainView(frame: view.bounds)
terrainView.world = MTTerrainWorld(seed: 1337)
view.addSubview(terrainView)

terrainView.onFrame = { tv, dt in
    // Your camera logic here — the library handles the rest.
    tv.setCamera(position: eye, target: lookAt, aspect: aspect)
}

For full control (custom MTKView, manual render loop), use MTTerrainRenderer directly. See Getting Started.

Features

🌍 Seeded infinite terrain

Deterministic heightmap — the same seed always builds the same world, on any device.

🧩 Chunked streaming

The world pages in around the camera; unused chunks are pooled and reused.

🎨 Data-driven biomes

7 built-ins keyed on height; add or override your own at runtime.

🔊 Exposed noise config

Seed, octaves, frequency, lacunarity, gain, domain warp, ridged mountain mode.

🏘️ Seeded structures

Houses, towers, trees, boulders, wells, windmills, dungeons — one instanced draw call per kind.

⚡ Metal renderer

Metal 4 fast paths where available, Metal 3 fallback. LOD handled internally.

☀️ Skybox + sun

Gradient sky with a visible sun disc that follows your sun angle.

✨ M3+ extras

Hardware ray-traced shadows and mesh shading on M3/M4/M5 and A17 Pro+.

📦 Zero assets

Vertex colors only — no textures, no downloads.
