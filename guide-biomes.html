Biome Authoring

Biomes turn raw heights into a world that reads — ocean vs. beach vs. forest vs. snow. This guide covers the mapping, the built-in table, and custom biome recipes.

How biomes map from height

Every point has a normalized height 0…1 (world.heightAt(x:z:)). A biome claims a slice of that range:

MTBiome(
    name: "grass",
    minHeight: 0.50,   // inclusive — heights >= 0.50 can match
    maxHeight: 0.65,   // exclusive — heights < 0.65 can match
    groundColor: SIMD3(0.25, 0.55, 0.20),  // linear RGB 0...1
    slopeColor: SIMD3(0.45, 0.38, 0.30),   // cliffs (optional)
    emitsLight: false
)

Key rules: minHeight is inclusive, maxHeight is exclusive. Stack ranges end-to-start for gapless coverage. Colors are linear RGB 0…1 (not sRGB 0–255). Biome colors bake into vertex colors at mesh build — don't animate them every frame.

The built-in table

MTBiome.default ships seven biomes tiling the full 0…1 range:

BiomeHeight rangeLook
deepOceanbottom of range → lowdark blue water floor
oceanlow → below sea levelmid blue water floor
beacharound seaLevel ≈ 0.45sand
grasslowlands above the beachgreen plains
forestrolling highlandsdarker, denser green
mountainhigh altitudegrey rock (with slopeColor cliffs)
snowyPeaktop of rangewhite

The beach band straddles config.seaLevel — raising sea level widens the ocean and narrows the land.

Custom biomes: the three operations

// Add a NEW biome (or REPLACE the one with the same name)
world.setBiome(MTBiome(name: "volcano", minHeight: 0.90, maxHeight: 1.0,
                       groundColor: SIMD3(0.15, 0.05, 0.05),
                       slopeColor: SIMD3(0.35, 0.10, 0.05),
                       emitsLight: true))

// Remove a custom biome you added (built-ins can't be removed individually)
world.removeBiome(named: "volcano")

// Throw away ALL custom biomes, restore the built-in table
world.resetBiomesToDefault()

Precedence rules

  1. Custom biomes are checked first, in insertion order. The first custom biome whose range contains the height wins.
  2. Built-ins are the fallback.
  3. setBiome with an existing name replaces in place — no duplicates.

A custom biome overlapping a built-in range shadows the built-in there — that's how you override snowyPeak.

Recipe 1: Higher mountains

// Snow starts lower and covers more of the highlands
world.setBiome(MTBiome(name: "snowyPeak",
                       minHeight: 0.80, maxHeight: 1.0,
                       groundColor: SIMD3(0.92, 0.94, 0.97),
                       slopeColor: SIMD3(0.55, 0.50, 0.58)))

// Stretch mountain down to meet it — no gap, no overlap
world.setBiome(MTBiome(name: "mountain",
                       minHeight: 0.68, maxHeight: 0.80,
                       groundColor: SIMD3(0.42, 0.40, 0.44),
                       slopeColor: SIMD3(0.30, 0.28, 0.32)))

Pair with noise.ridged = true and higher heightScale for jagged alpine terrain.

Recipe 2: Lava biome (with emitsLight)

world.setBiome(MTBiome(name: "snowyPeak",
                       minHeight: 0.88, maxHeight: 1.0,
                       groundColor: SIMD3(0.92, 0.94, 0.97),
                       slopeColor: SIMD3(0.55, 0.50, 0.58)))

// Lava fields between mountain and snow
world.setBiome(MTBiome(name: "lava",
                       minHeight: 0.80, maxHeight: 0.88,
                       groundColor: SIMD3(0.85, 0.18, 0.05),  // molten orange-red
                       slopeColor: SIMD3(0.25, 0.05, 0.03),   // cooled crust on cliffs
                       emitsLight: true))                     // glows in the shader

The fragment shader treats emitsLight vertices as self-illuminated — they skip NdotL darkening, so lava reads as glowing even at night. Tip: keep glowing bands narrow.

Recipe 3: Underwater biomes

// Tropical shallows: bright turquoise sand under the water
world.setBiome(MTBiome(name: "ocean",
                       minHeight: 0.15, maxHeight: 0.42,
                       groundColor: SIMD3(0.15, 0.65, 0.60)))

// Abyssal plain: near-black
world.setBiome(MTBiome(name: "deepOcean",
                       minHeight: 0.00, maxHeight: 0.15,
                       groundColor: SIMD3(0.01, 0.03, 0.06)))

The water plane (config.waterColor) is drawn translucent over these ground colors — the final look is the blend of the two.

Tips

  • Cover 0…1. Unmatched heights fall back to the built-in list.
  • Mind the sea. Keep water-adjacent bands near config.seaLevel.
  • Slope colors sell cliffs. Rock on mountains, dark loam in forests, pale sand on dunes.
  • Structures avoid some biomes — placement keeps to land between beach top and snow.
  • Name discipline: "SnowyPeak" ≠ "snowyPeak". Reuse exact built-in names when overriding.
